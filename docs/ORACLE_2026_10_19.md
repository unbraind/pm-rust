## Coverage resolution

Pair-preserving compaction cannot manufacture a lone surrogate. The unreachable
top-level CLI error handler and redundant post-compaction TOON validation were
removed. `compact_budget` now returns its result directly because that pass has
no remaining fallible operation.

The lossless JSON codec contract remains supported. A documented
`ListOutput::with_json_overrides` constructor allows callers to retain raw JSON
overrides with a Unicode-safe view. Serialization validates surviving raw
fragments; TOON refuses surviving overrides. Tests cover this refusal through
the binary's output writer and the library, including short escape fragments
that must return an error without panicking. The defensive unknown-sort arm is
tested directly. No coverage thresholds or exclusions change.

## Behavioral revert proof

With the new oracle and tests retained, reverting only the changed list
selection/page functions makes
`unbounded_list_matches_published_cli_and_golden` fail on the all-status SDK
golden. Reverting only `close_item` makes
`closure_sdk_fields_and_evidence_modes` fail on the successful close receipt.
Reverting only `ownership_item_with_options` makes
`claim_release_sequences_match_published_bytes_and_envelopes` fail on the
foreign-owner warn-release envelope. Restoring the old unconditional 240-unit
cut inside `compact_strings` makes
`lossless_views_keep_cuts_and_javascript_numbers` fail on the retained prefix.
Each proof requires an assertion failure, rather than a compilation failure;
the final implementation is restored after every run.

Separately, reverting the brief-row sort-value behavior makes
`brief_sort_values_survive_sdk_projection` fail. Reverting the changed
no-truncate producer-limit handling makes
`no_truncate_still_refuses_invalid_explicit_limits` fail. These exercise SDK
reads from plain trackers without Git.
